# Project Memory

## Core
Dark monochromatic theme. Primary orange (neon-orange). bg zinc-950/black.
Space Grotesk display, Inter body. Never bright colors.
Full-stack: React+TS frontend + Express/Prisma/Neon Postgres backend in backend/.
Auth via JWT (access+refresh httpOnly cookie). RBAC: student|trainer|admin.
"THE AFTER HOURS" — premium fitness accountability platform for college students.
Frontend calls backend at VITE_API_BASE_URL (default localhost:4000/api).
