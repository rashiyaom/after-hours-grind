# The After Hours Grind

Premium fitness and coaching platform designed for elite students and trainers. 

## Features
- Daily Plan & Mission Tracking
- Community Social Feed & Interactions
- Student & Trainer Dashboards
- Leaderboards & Achievements
- Progress Analytics

## Getting Started
1. Install dependencies: `npm install`
2. Run development server: `npm run dev`
3. Build for production: `npm run build`
